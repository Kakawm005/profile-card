Product Card — Kayque Pimentel

Um Product Card / Profile Card desenvolvido com HTML e CSS, inspirado em cards de redes sociais. O projeto apresenta informações de perfil, foto, redes sociais, botões de ação e métricas de interação.

🛠️ Como executar

Clone o repositório:

git clone https://github.com/seu-usuario/product-card.git

Entre na pasta:

cd product-card

Depois, abra o arquivo:

index.html

no navegador.

Também é possível utilizar a extensão Live Server do VS Code para executar o projeto localmente.

🎯 Objetivo

Este projeto foi desenvolvido como um exercício prático de HTML e CSS, com foco na criação de componentes visuais, organização de código e construção de uma interface semelhante a um perfil de rede social.
